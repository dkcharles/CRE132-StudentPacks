# CRE132 Student Packs

The hand-outs for the CRE132 Unity tutorials. Start with `CRE132_Tutorials.pdf`: it lists every
tutorial and the order to do them in.

Each tutorial folder holds a Starter project (zip), a worksheet (PDF) and a Finished project (zip).

Made by `Builders/pack.py` and `Builders/guide.py` in the CRE132-UnityTuts repo; don't edit by hand.
The art and sound in the zips are licensed for CRE132 coursework only: keep this repo private.
